### Kestrel Interactive Archive

**八款小游戏，一条藏在它们之间的故事。**

外表是一座独立游戏档案馆。玩着玩着，浏览器本身也会成为线索的一部分。支持中英双语，进度保存在浏览器本地。

[在线试玩 ↗](https://kestrel-interactive-archive.qadgunn.chatgpt.site/) · [代码与说明](https://github.com/yansuan0713/kestrel-interactive-archive)

### AI Werewolf Arena · 月下议事厅

**AI 坐上游戏桌，你来当主持人。**

本地运行的狼人杀与“爆炸项圈”主持台。把生成的提示词复制到 AI 网页，再把回复粘回来确认；程序负责规则结算和存档，主持人决定阶段推进。**无需 AI API Key。**

<sub>TypeScript · React · Vite · Express</sub>

[代码与运行说明 ↗](https://github.com/yansuan0713/ai-werewolf-arena#readme)
