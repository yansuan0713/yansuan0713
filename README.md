## 从这两件作品开始

### Kestrel Interactive Archive

**八款小游戏，一条藏在它们之间的故事。**

外表是一座失落的独立游戏档案馆。每款都能单独玩，继续逛下去，它们会渐渐拼出同一个谜团。建议先从首页开始，别急着翻源码。

- 页面标题、前进后退和焦点状态，也会参与玩法。
- 中英双语；进度保存在当前浏览器，可导出存档带走。

<sub>TypeScript · React · 浏览器本地存储</sub>

[在线试玩 ↗](https://kestrel-interactive-archive.qadgunn.chatgpt.site/) · [代码与说明](https://github.com/yansuan0713/kestrel-interactive-archive)

### AI Werewolf Arena · 月下议事厅

**AI 坐上游戏桌，你来当主持人。**

在自己的电脑上开一桌狼人杀，或玩一局“爆炸项圈”。把提示词复制到 AI 网页，再把回复粘回来、检查并确认；程序负责规则结算，阶段由你推进。**无需 AI API Key。**

- 每个席位获得各自的信息；回复解析后由主持人确认。
- 对局可保存、恢复；公开战报与结束后的完整复盘可分别导出。

<sub>TypeScript · React · Vite · Express</sub>

[代码与运行说明 ↗](https://github.com/yansuan0713/ai-werewolf-arena#readme)
